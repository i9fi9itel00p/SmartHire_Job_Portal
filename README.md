SmartHire — Job Portal System (Java + JSP + Servlet + MySQL)

A complete Job Application and Recruitment Management System built using Java (JSP/Servlet), JDBC, and MySQL.
This project allows job seekers to apply for jobs and recruiters to post and review applications.

🚀 Features
    👤 User (Job Seeker)
        Create account & login
        View latest jobs
        Apply for jobs
        Upload resume
        View application status
    🧑‍💼 Admin / Recruiter
          Add new job postings
          View all applications
          Shortlist or reject candidates
